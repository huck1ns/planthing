# Planthing

<img width="310" height="465" alt="image" src="https://github.com/user-attachments/assets/4c0d9750-9666-455e-b15e-4a3356cc41e8" />

Planthing is an Arduino powered plant monitoring program. Integrated with the Perenual API to pull preferred moisture and light levels for over 3000 plants, the program compares your plant's conditions to the ideals. Within the application you can search the database of plants and easily update the ideal conditions. 

<img width="250" height="150" alt="image" src="https://github.com/user-attachments/assets/e63d39c5-99b2-4a93-96e8-6d531e10e14c" />

GUI application written by Jack Huckins in Python using PySide6 Graphical framework. Sensor code written in Arduino language, with the circuit assembled by collaborator Samuel Hallgren.
